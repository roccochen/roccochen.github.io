到 GitHub 提问

要装什么东西吗？

不用。它是一个网页，在浏览器里打开就能用，手机上也可以。

需要登录或付费吗？

不需要。没有账号系统，也没有收费入口，打开就会出现工具。

我的装备数据会被传走吗？

不会。所有计算都在你的浏览器里完成，价格数据也是你自己录入的。

市集页插件什么时候能用？

还没定。做出来会先放在这一页上，项目列表里也会标成已上线。

成功率准吗？

按内置权重与品级分布估算，用来比较顺序和花费；真实结果会有浮动。
